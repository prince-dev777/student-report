3. RENDER PAR FREE WHATSAPP WEB SETUP (PUPPETEER / BAILEYS + MONGODB)
================================================================================

Render (Linux Cloud) par Free WhatsApp chalane ke 2 best solutions:

--------------------------------------------------------------------------------
OPTION 1: WhatsApp-Web.js + RemoteAuth (MongoDB Atlas Store)
--------------------------------------------------------------------------------
- Code: `wwebjs-mongo` ya Baileys MongoDB auth store.
- Session save: MongoDB Atlas ke `wwebjs_sessions` collection mein session save
  hota hai.
- Puppeteer on Linux Render:
  Render pe Chromium ke saath headless browser run hota hai.
  Puppeteer launch flags:
  `['--no-sandbox', '--disable-setuid-sandbox', '--disable-dev-shm-usage', '--single-process', '--no-zygote']`

--------------------------------------------------------------------------------
OPTION 2: Baileys Engine (@whiskeysockets/baileys) - (ULTRA LIGHTWEIGHT)
--------------------------------------------------------------------------------
- Baileys direct WhatsApp WebSocket use karta hai (No Chrome / No Puppeteer).
- Memory: Sirf 25MB RAM leta hai (Render ke 512MB free tier pe super-fast chalta hai).
- 100% Free, QR code scan once, session stores in MongoDB Atlas.

4. BIOMETRIC MACHINE ON-SCREEN CONFIGURATION (STEP-BY-STEP)
================================================================================

Apni Biomax / FK Machine ke screen par yeh settings karein:

STEP 1: NETWORK & WI-FI SETUP
------------------------------
1. Machine Menu > [Comm.] > [Wi-Fi / Network] mein jayein.
2. Institute ke Wi-Fi se connect karein.
3. Settings:
   - Gateway: 192.168.0.1 (Aapke Wi-Fi Router ka IP)

STEP 2: CLOUD SERVER / WEB SERVER SETTINGS
-------------------------------------------
1. Machine Menu > [Comm.] > [Cloud Server] / [Web Server] / [ADMS] mein jayein.
2. Values fill karein:
   - Enable Server / Cloud: ON / YES
   - Server Address / Domain: student-report-4j6t.onrender.com
     *(Note: "https://" mat lagana, sirf domain name likhna)*
   - Server Port: 80 (ya 443)
   - Request URL / Protocol: FK Web Protocol (ya /hdata.aspx)
   - Push Interval: Realtime (1s)

3. [M/OK] press karke save karein aur Home screen par aa jayein.
4. Screen par Cloud icon Connected (Green) show hoga.
